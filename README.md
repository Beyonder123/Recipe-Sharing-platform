# 🍳 Recipe Sharing Platform

A simple **Recipe Sharing Platform** built using **HTML, CSS, and JavaScript**.  
This project serves as a beginner-friendly front-end website that allows users to explore and view recipes in a clean, visually appealing interface.

---

## 🧾 Overview

This project was created as a first website project — a simple static web application that showcases recipes.  
It focuses on design, layout, and interactivity using only front-end technologies.  

Currently, the site is fully static, but can easily be expanded into a full-stack project with a backend and database integration.

---

## 📁 Project Structure

| File / Folder | Description |
|----------------|-------------|
| `index.html` | Main landing page of the website |
| `home.html` | Additional content or homepage view |
| `about.html` | Information about the project or creator |
| `app.css`, `home.css` | CSS files for layout and styling |
| `app.js` | Handles interactivity and front-end logic |
| `images/` | Contains sample recipe images |
| `Coffee Soda.ttf` | Custom font used for styling |
| `LICENSE` | Apache 2.0 License for open-source usage |

---

## ✨ Features

- 🥘 Browse beautifully presented recipes  
- 🎨 Clean and simple design using HTML & CSS  
- 🔤 Custom font and consistent theme  
- 📱 Fully client-side — no backend required  
- 🧭 Easy navigation between pages
